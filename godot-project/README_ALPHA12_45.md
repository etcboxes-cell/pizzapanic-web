# Alpha 12.45 — Guided First Day and gradual expansion

- Interactive 10-step Level 1 guide, pausing gameplay clocks while instruction dialog is open. Skip option and replay tutorial button on briefing screen.
- Every store purchase requires a confirmation popup with the benefit, exact price and remaining balance.
- 3 tables in Levels 1–5; optional extra chairs unlock at Level 3. Fourth table at Level 6, fifth at Level 11, sixth at Level 16.
- Level 13 tray is mandatory, purchased once using the entire wallet at that moment. Before purchase waitress carries one pizza; after purchase two.
- Existing save file location unchanged. No campaign reset in this update.

## Playtest checklist
1. Start Level 1, follow all ten tutorial steps; verify time and patience do not run while a dialog is visible.
2. Try SKIP TUTORIAL, then REPLAY LEVEL 1 TUTORIAL from the briefing.
3. Open store and verify confirmation Cancel vs Buy behavior.
4. Check table count progression and one-pizza carrying until tray purchase.
5. Purchase tray and verify wallet zero, permanent ownership, and two-pizza carrying.

This build was statically edited and ZIP-verified; Godot runtime/export testing was unavailable in this environment.
