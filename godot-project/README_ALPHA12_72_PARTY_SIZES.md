# Pizza Panic Alpha 12.72 — Early Party Size Progression

Updated from Alpha 12.71 with the user-approved first-five-level customer rules.

| Day | Number of arriving parties | Sizes allowed | Notes |
| --- | ---: | --- | --- |
| 1 | 8 | 1 or 2 | First group is 2 for the tutorial; gentle singles/couples |
| 2 | 9 | 1 or 2 | No large-party requirement; mission is now serve 7 guests |
| 3 | 10 | 1, 2, 3 or 4 | Guarantees a 3-person and a 4-person party for introduction |
| 4 | 11 | 1, 2, 3 or 4 | More 3- and 4-person groups |
| 5 | 11 | 1, 2, 3 or 4 | Rush Day with still more large groups |

Red tables (four seats) are required for parties of 3 or 4. Yellow tables seat up to 2 unless upgraded. No change to table seating code, payment, chef, waitress, customer sprites, ingredient logic, or save data.

Level 2 challenge changed because seating two 3/4-person groups would be impossible under the new limit. Level 3 tutorial briefing now explains the arrival of large groups.

Validation: the source ZIP integrity and the updated gameplay rules have been checked statically. An actual Godot gameplay session has **not** been run in this environment.
