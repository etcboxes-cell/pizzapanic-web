# Alpha 12.53 — Interactive approved restaurant layout
Open `scenes/RestaurantVisualPreview.tscn` and press F6 in Godot 4.7.2.
Tap any active table to simulate seating/clearing; use +TABLE and -TABLE to preview tables 7 and 8 unlocking. The first six tables are active in this layout prototype.

This is a visual interaction prototype, not yet the campaign gameplay replacement. The illustration is a single flattened image, and its depicted characters/objects cannot animate independently. The main scene, campaign mechanics, and saved progress are not modified.
