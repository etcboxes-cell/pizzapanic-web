# Fresh start / Alpha 12.12
This build uses `user://pizza_panic_twostep_fresh_v1.cfg` rather than `user://pizza_panic_progress.cfg`. The original campaign progress is untouched. The new version starts at Day 1 with zero coins and no purchases. Unzipping into a new folder is recommended.

Double pizza orders appear starting Day 7 (roughly every fourth party); that table must receive both pizzas before eating. Double dishes appear starting Day 13 (every third party): wash one set, then collect and wash the next. Buy cart upgrades from the pre-level Store.
